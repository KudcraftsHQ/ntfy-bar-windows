# ntfy-bar-windows

A small Windows tray client for [ntfy](https://ntfy.sh), built for self-hosted servers. It is the
Windows sibling of [ntfy-bar](https://github.com/KudcraftsHQ/ntfy-bar) (macOS) and shares its
settings model, so the two apps behave the same way.

Work in progress — see the open pull request.
